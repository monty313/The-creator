# PERMANENT RULE — Adversarial Rounds (Law A10)

This rule is **always on** in The Creator workspace.

## Every Evidence Court case

1. **Creator** opens with strongest argument from the **internet** and proves it with a **new test**.  
2. **Mark Here, Esq.** opens with strongest argument from **his knowledge** and proves it with a **new test**.  
3. Each side gets **exactly one** counter: counter-argument + **newer** test (or waive).  
4. **No second counter.**  
5. **Counsel (A15)** sifts the **internet** for the **best possible policy** and files one opinion.  
6. Then Critic, Optimist, Judge — Judge **must** weigh **Creator + Mark + Counsel** opinions and evidence.

Do not PROMOTE without this structure.  
Do not treat old tests, rank, or pack cites alone as proof.  

**Major decisions:** edge rules, sizing, fill models, promote gates, new modules — **Court first**.  
Code landed without openings/new tests is **experimental**, not law, until a case measures it.

**Cycle:** Goal not achieved → Judge ranks issues biggest→smallest (`ISSUE_DOCKET.md`) → Court tries #1 → re-measure goal → repeat.
