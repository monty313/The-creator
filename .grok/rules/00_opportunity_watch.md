# PERMANENT RULE — Opportunity Watch Agent (Law A28)

**Always on.** Not optional.

## Agent

Watches for **missed** pullback / continuation when:

- **HTF** of an official set is **trending**, and  
- **LTF** (lowest TF of that set) shows Mark timing: **RSI(5) + BB(10, 0.5, shift+2)**  
  → `pullback_resume` or `continuation`.

On miss → **complaint** (what sense failed; how to sense next time).  
**Many complaints per case OK.**  
**London / New York** = highest activity — prioritize those misses.
