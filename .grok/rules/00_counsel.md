# PERMANENT RULE — Counsel to the Court (Law A15)

This rule is **always on** in The Creator workspace.

## Role

**Counsel** helps the **Judge deliberate**.  
Job: **sift the internet** for information that builds the **best possible policy**.  
Presents **one opinion** per case (not production code).

## Three opinions (mandatory)

Judge **must** view and weigh **all three** + evidence before ruling:

1. **Creator** — internet argument + new tests (A10)  
2. **Mark** — knowledge argument + new tests (A10)  
3. **Counsel** — internet sift + policy recommendation + sources/evidence  

PROMOTE without three-opinion deliberation → **Forbidden**.

## Sequence

After Creator/Mark counters → **Counsel opinion** → Critic → Optimist → Judge IRAC  
(IRAC Application must name Creator, Mark, and Counsel).
