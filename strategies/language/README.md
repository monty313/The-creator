# Strategy language catalog (cited sources only)

**What this is:** plain-language inventory of trading strategies found on this machine and a few public repos.  
**What this is not:** Court law, production code, or a code dump.

## Citation rules

1. **Machine files** → absolute path in backticks (example: `C:\Users\user\...`).  
2. **MetaTrader** → path under `%APPDATA%\MetaQuotes\Terminal\...`, or ARMY/Downloads path.  
3. **Public GitHub** → full `https://github.com/...` URL + license note.  
4. **No strategy source code** is stored in this `language/` tree—only descriptions and citations.

## Scope honesty

- Not a full scan of every drive or cloud-only OneDrive file.  
- MT4 terminal: **no custom strategy EAs** (stock samples only).  
- One ARMY `.mq4` template language: MA ribbon filled_Alerts.  
- Originals remain at the cited paths; this folder is the language index only.
