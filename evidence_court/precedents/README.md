# Precedent Cards

One short card per closed case: `CASE-XXXX.card.md`.

Required sections:

1. **question**  
2. **ruling**  
3. **goal_axes**  
4. **scoreboard_delta**  
5. **evidence** (ledger `event_id`s + artifact paths)  
6. **do_not_reargue_unless**  

Load these before re-opening related Full Court topics (Law **A33**).
